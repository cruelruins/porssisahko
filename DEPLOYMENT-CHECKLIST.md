# Julkaisun tarkistuslista

## Ennen ensimmäistä julkaisua

- [ ] Repositoryn oletushaara on `main`.
- [ ] `site/index.html`, `site/styles.css` ja `site/app.js` ovat GitHubissa.
- [ ] Azure App Service tai webhotelli on luotu.
- [ ] FTPS on käytössä ja kohdehakemisto on tarkistettu.
- [ ] GitHub Secrets sisältää `FTP_SERVER`, `FTP_USERNAME` ja `FTP_PASSWORD`.
- [ ] `server-dir` vastaa palvelimen oikeaa julkaisukansiota.

## Julkaisun jälkeen

- [ ] Actions-ajo näkyy vihreänä.
- [ ] Sivusto avautuu selaimessa.
- [ ] Hintatiedot latautuvat.
- [ ] Tehty HTML/CSS/JS-muutos näkyy palvelimella.
- [ ] Palautuspohjaan on lisätty GitHub-linkki, sivustolinkki ja kuvakaappaus onnistuneesta ajosta.
